FIRST TIME
1. Go to github.com/MihailoJovic/Guild-Milestones/releases/latest and download GuildMilestones.exe.
2. Put it in a folder you'll keep, e.g. Documents\Guild Milestones. (Right-click it > Send to > Desktop for a shortcut.)
3. Double-click it. If Windows says "Windows protected your PC": More info > Run anyway.
4. Follow the "Get set up" checklist on the Home page.

UPDATING LATER (one click)
When a new version exists, a blue "Update to vX" button appears at the bottom left of the app.
Click it. The app downloads the update, restarts, and refreshes the addon in your game folder.
Then type /reload in the game.

Your settings and the app's memory live in %APPDATA%\GuildMilestones, so updating never wipes them.

ONE APP, ONE FOLDER
Keep only ONE copy of the app. The Game & addon page shows the folder it runs from.
